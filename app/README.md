# 小猫桌面宠物（Q 版长毛银渐层）

一款类 QQ 宠物的 Windows 桌面陪伴程序。主角为基于你的爱猫照片转化的 **Q 版长毛银渐层**，支持开机自启、用户交互与无交互时的自由活动。

技术栈：**Electron + HTML5 Canvas 2D**，全部素材本地生成与处理，无外部依赖。

---

## 一、快速开始

### 环境要求

- Windows 10 / 11
- Node.js ≥ 20（开发/运行需要；CI 使用 22）

### 开发模式运行

```bash
cd app
npm install
npm start
```

### 打包为 exe

```bash
cd app
npm install          # 含 electron-builder
npm run dist         # 同时产出便携版 + 安装版
npm run dist:portable  # 只产出便携版
```

产物位于仓库根目录 `dist/`（打包输出已配置到应用目录之外）：

| 产物 | 说明 |
|------|------|
| `CatDesktopPet-Portable-1.0.0.exe` | **便携版**：单文件免安装，双击即用，可放 U 盘随身携带 |
| `CatDesktopPet-Setup-1.0.0.exe` | **安装版**：NSIS 一键安装（写入用户目录，可选桌面快捷方式，完成后自动运行） |

打包方式：**electron-builder**（asar 归档 + Electron 31 运行时），应用图标 `build/icon.ico` 由精灵图 `idle.png` 自动生成（256/128/64/48/32/16 多尺寸）。用户数据（配置、备份）保存在 `%APPDATA%/cat-desktop-pet`，与程序目录分离，替换 exe 不丢数据；首次启动会自动写出默认 `config.json`。

> **注意**：在注入了 `ELECTRON_RUN_AS_NODE=1` 或 `NODE_OPTIONS`（--require 垫片）的终端里从命令行启动 exe 会失效（被当作纯 Node 运行，表现为进程驻留但无窗口）。日常使用请直接**双击 exe**，或在启动前清除这两个环境变量（`env -u ELECTRON_RUN_AS_NODE -u NODE_OPTIONS ./CatDesktopPet.exe`）。

### 1. 交互方式

| 操作 | 效果 |

| 按住猫拖动 | 拎起猫并移动到任意位置，松手后落地 |

| 右键点击猫 | 弹出功能菜单：抚摸 / 喂食 / 逗玩 / 呼喊 ┃ 状态面板 / 设置… ┃ 退出 |
| 托盘菜单 | 抚摸 / 喂食 / 逗玩 / 呼喊 / 静音 / 设置… / 退出（体型、自启动、点击穿透请到设置） |
| 双击托盘图标 | 呼喊小猫 |
| 全局热键 `Ctrl + Shift + C` | 呼喊小猫 |

### 2. 体型调整（尺寸边界）

| 项 | 值 | 说明 |
|----|-----|------|
| 显示 100% 基准 `SIZE_100` | 0.88 | 设置 / 气泡里的百分比以此为 100% |
| 设计基准 `BASE_SCALE` | 0.62 | 阴影半径、命中区等按此实测，仅作比例参考 |
| 最小 `MIN_SCALE` | 0.18 | 显示 20%（迷你体型） |
| 最大 `MAX_SCALE` | 0.88 | 显示 100%（上限） |
| 步长 `SCALE_STEP` | 0.04 | 滚轮每格（每格 5%） |

**窗口与穿透**：宠物窗口为 640×640 透明画布（为容纳 150% 体型）。为避免大窗口遮挡桌面点击，
实现了**动态鼠标穿透**：鼠标不在猫身 / 菜单 / 拖拽中时，窗口事件穿透到下层程序
（`setIgnoreMouseEvents(true, {forward:true})` + 渲染进程按悬停位置动态接管）；
「点击穿透」设置开启时则始终穿透。窗口放大后旧坐标经 configVersion 2→3 迁移自动平移，
保证猫在屏幕上的位置不变。

**边界条件处理**：

- 达到上限/下限时给出气泡提示（"已经是大喵形态啦" / "再小就要看不见啦"），且不产生位置突变；
- 活动边界 `bounds()` 按素材真实半宽 × 体型标定（**实测半宽 253px**，取自最宽帧 walk_3 左缘；此前按 215px 估算，曾导致面板与猫身重叠约 26px），任何体型下猫身（含跨步姿态）都完整留在窗口内、不被边缘裁切；
- 状态面板显示时做**双向避让**：主进程 `syncPanelPos()` 计算面板贴靠侧并推送 `panel-side`，渲染端把猫的活动边界从对应一侧收紧（面板间距 `PANEL_GAP = 12px`），实机三档体型（100% / 60% / 20%）像素级校验猫身与面板最小间隙均 > 0；
- 命中区 `hitCat()` 半径同比缩放，大猫更好点中、小猫不遮挡桌面；
- 体型持久化到 `config.json`，重启恢复；配置被手工改坏时夹回 `[0.18, 0.88]`。

**阴影圆盘与说话气泡联动**（本轮修复项）：

- **阴影**：圆盘半径按 `当前体型 / 设计基准` 等比缩放，并按离地高度同步淡出收缩，始终与猫脚接触面匹配；
- **气泡**：每帧挂到猫头顶正上方（间距 2px，紧贴宠物），**尺寸固定、不随宠物体型缩放**（字号由「界面文字缩放」设置控制），任何体型下文字都清晰可读；尖角始终指向猫头——猫走到窗口边缘、气泡被夹紧时，尖角经 `--tail-x` 横向偏移仍指向头顶；头顶位置由 `animator.contentTop()` 实测当前帧内容边界得出，并做指数平滑以消除帧序列切换的微小抖动；
- **根因修复**：`animator._drawOne` 中 `drawImage` 的宽高重复乘了缩放系数（`ctx.scale` 已缩放一次），实际渲染尺寸曾是 scale²，导致猫比设计尺寸小一圈、气泡"离猫很远"、阴影比例失调。修复后猫恢复设计尺寸，阴影/命中区/边界/气泡全部回归同一套线性换算。

### 3. 右键菜单自动关闭

覆盖全部边界场景：

1. 窗口内点击菜单外部（猫身、空白处）；
2. 点击本窗口之外的桌面/其他程序 —— 渲染进程收不到 `pointerdown`，依靠窗口 `blur` 关闭；
3. `Esc` 键；
4. 滚轮滚动；
5. 点击菜单自身（无论点中条目还是空白/分隔线）。

### 4. 帧序列与帧间插值

`walk` / `run` 已由单姿态升级为**序列帧 + 帧间插值**，这是本轮解决"腿部动作僵硬"的核心手段。

| 姿态 | 帧数 | 帧率 | 说明 |
|------|------|------|------|
| `idle` | 4 | 5 fps | 呼吸循环；常态只在睁眼帧之间轮播，眨眼由独立随机时钟触发（见下） |
| `walk` | 4 | 11 fps | 四足交替落地，含重心转移与身体起伏 |
| `run` | 4 | 13 fps | 四足腾空瞬间收腿，含前倾与更大起伏 |
| `eat` | 4 | 6 fps | 低头咬食 → 咀嚼 → 抬头吞咽 → 舔食 |
| `play` | 4 | 8 fps | 举爪蓄力 → 拍球 → 兴奋后仰 → 低头盯球 |
| `pet` | 3 | 6 fps | 被抚摸蹭头三连（左右蹭 + 仰头满足） |
| `jump` | 3 | 5 fps | 下蹲蓄力 → 腾空舒展 → 落地挤压（单次播放，周期 ≈ 腾空时长 0.62s） |
| `stretch` | 3 | 5 fps | 起势 → 最深伸展 → 回弹（单次播放后定格） |
| `sleep` | 3 | 4 fps | 趴睡呼吸循环（含耳朵轻动） |
| `meow` | 3 | 7 fps | 开口 → 张嘴喵 → 合嘴收尾 |
| `tailwag` | 4 | 7 fps | 摇尾巴（非交互自主动作） |
| `unhappy` | 2 | 2 fps | 不高兴（非交互自主动作） |
| `bath` | 6 | 6 fps | 洗澡（坐盆 → 泡泡 → 抖身水花 → 冲净 → 甩尾收尾） |
| `drag` | 1 | — | 被拎起（单姿态） |

**待机眨眼**（`engine/animator.js` 的 `blinkCfg` / `_scheduleBlink`）：眨眼的触发独立于帧序列，由一条累加时钟驱动。

- `idle` 常态只在两帧睁眼之间（`idle_1` ↔ `idle_4`）轮播，困倦半闭的 `idle_2` 退出循环，闭眼的 `idle_3` 只在眨眼瞬间插入；
- 每次眨眼结束按「频率」重新排期：`meanGap = 60 / blinkRate` 秒，实际间隔取 `meanGap × (0.55 + rand × 0.9)`，即 **±45% 随机抖动**，避免固定周期的机械感；
- 闭眼定格时长固定，结束后把后继帧指回眨眼前的睁眼帧，插值不闪跳；
- 频率为 0 时完全不眨眼；切走非 `idle` 姿态会立即清掉闭眼状态，不会卡住；
- 设置改动即时作用于运行中的实例（`applyConfig` 每轮重写 `animator.blinkCfg`），无需重启。

**插值原理**（`engine/animator.js`）：

- 每帧时段的后 **35%**（`FRAME_BLEND = 0.35`）与下一帧做交叉淡化，曲线为 `Core.Ease.inOutQuad`；
- 即播放 `frames[i]` 的同时叠加 `frames[i+1] * k`，`k` 从 0 平滑升至 1；
- 效果等效于把 4 帧循环"加密"为连续过渡，肉眼几乎看不到帧跳变；
- 帧推进使用 `while` 循环防丢帧（低帧率环境下自动补步，最多 16 步），保证动画时长与真实时间一致。

**避免"双重动画"**：帧序列本身已包含肢体运动，因此 `computeMods()` 中 walk / run 的程序化起伏与倾斜幅度被收敛（walk bob 4→2.4、tilt 0.035→0.02；run bob 6→3.2、tilt 0.06→0.04），避免帧动画与正弦微动互相打架产生抖动。

循环预览见 `../assets/previews/walk_cycle.png`、`../assets/previews/run_cycle.png`（每个循环展开为 24 个子帧，可直观检查腿部交替）。

### 5. 自主行为（无交互时）

- **待机**：呼吸起伏、随机眨眼（设置 → 行为与活动 →「眨眼频率」0–30 次/分钟，默认 8，0 = 不眨眼）；心情「良好」档呼吸略放大稍快，清洁「危急」档每 3.6s 来一次 0.6s 高频轻抖（表现「痒」）
- **走 / 跑**：随机选择目标点横向移动，到屏幕边缘自动转身；跑跳概率随属性档位实时增减
- **跳**：随机起跳，带重力下落与落地挤压缓冲
- **睡觉**：体力「危急」强制入睡；趴睡倾向 = 设置基准（默认 70%）+ 活跃度偏移 + 四项属性档位修正（困 +25、心情好 −5、饿极 −15 等），冒 Zzz，精力逐渐恢复，睡醒自动伸懒腰
- **主动呼喊**：长时间无人理睬时，猫会抬头喵叫并冒气泡求助
- **伸懒腰**：随机表触发（体力偏低时概率上调）
- **摇尾巴**：随机表触发的小动作（2.2–3.6 秒）；心情好 / 毛发干净时概率明显上调，脏到极危时**完全停止**（掩饰不适）
- **不高兴**：心情「偏低」档 40% 概率、「危急」档 50% 概率触发（2.6–4.2 秒），伴随情绪气泡台词

### 6. 属性系统

**统一降速基准**：默认**每 30 分钟下降 20 点**（约 0.011 点/秒），心情与好感例外（心情默认 5 点、好感默认 3 点，两者天然更耐久）；在设置 → 状态与成长中为**每种属性单独**设置「每 30 分钟下降点数」（0–20，下拉框），换算成匀速下降（面板数值平滑变化）；0 = 该属性不随时间下降（该项养成暂停）。趴睡时饱食约按 1/3 速度、清洁 ×0.25、好感不掉；奔跑/玩耍时清洁 ×2.2；睡觉时体力恢复。

| 属性 | 衰减（100% 基准） | 恢复方式 |
|------|------|---------|
| 饱食度 | 持续缓降；趴睡时约为活动时的 1/3 | 喂食（+42） |
| 精力 | 活动时缓降 | 睡觉（+9/s）、趴睡 |
| 心情 | 活动时缓降；趴睡时极缓慢回升 | 抚摸 / 逗玩 / 洗澡 |
| 清洁 | 缓降；奔跑 / 玩耍 ×2.2，趴睡 ×0.25 | **洗澡（+55）** |
| 好感 | 极缓下降；趴睡时保持不变 | 互动（抚摸 +3 / 逗玩 +3 / 喂食 +2 / 呼喊 +1 / 洗澡 +2） |

**趴睡为主**：无人互动时以趴着睡觉为主（默认 70%，设置 → 行为与活动 →「趴睡倾向」0–100% 可调；活跃度低/高自动 ±偏移），偶尔起身走原随机行为表。单次趴睡 30–70 秒，醒来自动伸懒腰。

**属性驱动气泡与行为**（`engine/needs-profile.js` 单一来源）：心情、清洁、饱食、体力四项**实时**决定猫说什么、做什么。每项按阈值分四档：

| 属性 | 危 critical | 偏低 low | 良好 good |
|------|------------|----------|-----------|
| 饱食 | `< 15` | `15–34` | `≥ 70` |
| 体力 | `< 15` | `15–34` | `≥ 70` |
| 心情 | `< 20` | `20–44` | `≥ 70` |
| 清洁 | `< 15` | `15–39` | `≥ 70` |

- **联动规则**（`decide()` 按 P1–P10 仲裁，一次只出一个行为 + 一句气泡）：
  体力危 → 强制入睡 → 饱食危 → 强制讨食 → 清洁危 → 蔫下来 / 喵叫 → 心情危 → 闹小情绪 / 求安慰 → 心情偏低 40% 闹小情绪 → 其余偏低档概率性提醒 → 长时间无互动 → 全良好时 6% 概率给一句正向台词（200s 冷却）→ 趴睡倾向 → 加权随机表。
- **行为权重**：四项档位的乘子逐列相乘后归一化——又困又饿 → 不跑不跳、多发呆多伸懒腰多喵叫；心情好 + 毛发干净 → 跑跳与摇尾巴明显增多；脏到极危 → 不再摇尾巴。
- **实时性**：属性穿过阈值的那一刻立即反应（恶化给警示台词、回升到正常/良好给恢复台词，20s/属性 冷却）；危急需求不等下一次决策 tick、在可打断状态下立刻切换（8s/需求 冷却）；交互结算的属性跳变同样被捕获——喂食后 1.2s 内先说「谢谢主人」再补一句「吃饱饱，好幸福～」。
- **限流**：全局自主气泡 5s；同一属性常规提醒 90s、危急 45s、跨档即时反应 20s、正向 200s；交互结算台词有 1.2s 保护不被覆盖。
- **睡眠中不被唤醒**：睡着时不响应「饿 / 累」等危急需求（避免趴睡节奏被打碎），醒来立刻补检。
- **阈值抖动防护**：升档需越过「阈值 + 4」的迟滞线（34.9 仍算偏低、39 才回到正常），降档越界即生效。
- **灵敏度**：设置 → 行为与活动 →「提醒灵敏度」（宽松 −8 / 标准 0 / 严格 +8，整体平移危险与偏低阈值，不影响良好档）。
- **总开关**：设置 → 行为与活动 →「状态驱动气泡与行为」；关闭后属性不再影响台词与动作倾向（清洁完全退出），仅保留体力 / 饱食的危急保护，用于对照排查。
- **洗澡入口恒开放**（1.0.0 起「允许洗澡」设置下线）：清洁类台词始终可用完整句式。

**洗澡**：右键菜单 / 托盘 / 状态面板「洗澡」触发。就地坐进浴盆约 4.5 秒（6 帧动画 + 泡泡粒子），结束时清洁 +55、心情 +10、体力 −6、好感 +2、经验 +6。

**年龄**：设置 → 宠物 →「出生日期」（`date` 控件，不允许未来日期）。状态面板徽章显示年龄替代等级，精度可在「精确到天 / 精确到月」间切换（3 岁 128 天 / 3 岁 4 个月）；未设置时显示「生日未设置」。经验字段保留但不展示。

属性持久化在数据目录的 `config.json`（默认 `%APPDATA%/cat-desktop-pet`），重启不丢失。

### 6.5 状态面板

参照参考图实现的独立置顶小窗（212×496），**紧贴猫身左缘**（按当前体型实时计算，体型变化即重新贴合；屏幕左缘放不下或猫过大时自动翻到猫身右侧），纵向对齐猫身中心，随宠物拖动实时跟随：

- **头部**：宠物名字 + 年龄徽章（精度随设置切换）；
- **台词行**：同步宠物气泡的最新文案（气泡消失即清空）；
- **档位徽章**：心情 / 饱食 / 体力 / 清洁四项中非「正常」档的属性各显示一枚小徽章（如「😊 很开心」「🫧 有点脏」「😢 很难过」），危急红 / 偏低琥珀 / 良好绿，全正常时整行隐藏；
- **数值条**：心情（黄）/ 饱食（绿）/ 体力（橙）/ 清洁（青）/ 好感（粉），0.25s 节流实时刷新；
- **互动区**：抚摸 / 喂食 / 逗玩 / 呼喊 / 洗澡 五个按钮（3 列网格），点击等价于右键菜单对应项；
- **自动关闭**：点击桌面或其他程序时自动收起（含 400ms 轮询兜底）；重新打开时自动贴近宠物当前位置。

效果预览：`../assets/previews/panel-tiers-light.png`（浅色）与 `../assets/previews/panel-tiers-dark.png`（深色）。

开关：右键菜单「状态面板」即时切换；设置 → 外观与主题 →「状态面板」记忆默认状态（默认开）。面板随主题（浅/深）与界面语言联动。

### 6.6 AI 自言自语（1.9.0 新增）

没有输入框、没有对话记录——猫只**单向**自言自语：讲笑话、讲故事、念诗、出谜语（自问自答）、科普猫咪常识、随口抱怨。

- **触发**：没人理它满 1 分钟后按「自主频率」随机开口（经常 1–2 分钟 / 平常 2–5 分钟 / 偶尔 5–10 分钟，深夜 23–07 间隔翻倍）；设置页「现在讲一段」可手动试听。
- **呈现**：每句一个气泡，按字数停留 1.5–6 秒；诗句保留分行；抚摸、喂食、拖动等交互会立刻打断，优先响应你。
- **声音**：默认「喵语节奏」（每段首句一声轻喵），可改「朗读」（系统 TTS，语速 80–140%）或「静音」。
- **模型**：OpenAI 兼容协议（默认智谱 GLM-4-Flash，免费无需充值；另含硅基流动 / 魔搭 / 百炼 / 火山方舟 / DeepSeek / Moonshot / 本地 Ollama 预设），流式生成、边生成边播报；温度 0.9，按类别限制句数与字数（笑话语 3 句、故事 5–8 句）。
- **降级**：无 Key、断网、Key 失效，或 8 秒内没憋出第一句 → 自动改用内置 88 条离线语料，不弹错误打断你；失败原因可在设置页「连接测试」查看。
- **防重复**：本地记录最近 20 条，同一内容 3 天内不再讲；最近讲过的标题会回灌给模型让它换题材。
- **成本保护**：按类别限制句数与字数（笑话 ≤3 句 / 故事 ≤8 句等）、内置 token 预算、单次 60 秒总超时、首句 8 秒降级；1.0.0 起不再设每日次数上限。
- **密钥安全**：API Key 单独存 `<数据目录>/ai-secret.bin`，用 Windows DPAPI 加密，不写入 `config.json`，界面只显示 `sk-****abcd`。

### 7. 设置窗口

**入口**：托盘菜单「设置…」或宠物右键菜单「设置…」；全局仅一个实例，重复打开会聚焦已有窗口。

**形态**：独立窗口 620×580（标准标题栏、非置顶、非模态），左侧 9 组导航 + 右侧表单。
表单**完全由 `engine/config-schema.js` 字段定义表驱动**——分组、控件类型、取值范围、默认值、生效徽标都来自 schema，界面代码不硬编码任何设置项。

**9 组 56 项**（界面语言固定中文，不提供切换项）：

| 分组 | 项数 | 代表项 |
|------|------|--------|
| 宠物 | 4 | 宠物名字（1–12 字符）、主人称呼、体型、出生日期 |
| 启动与运行 | 3 | 开机自启动、静默启动、记住窗口位置（单实例固定开启，无设置项） |
| 交互 | 5 | 点击穿透、滚轮缩放、呼喊快捷键、双击托盘呼喊、限制活动区域 |
| 声音与通知 | 8 | 静音、音量、喵叫与叫声音量、气泡开关与时长、系统通知与最短间隔 |
| 外观与主题 | 8 | 主题、字号缩放、不透明度、阴影、粒子、减少动态效果、状态面板、年龄精度 |
| 行为与活动 | 7 | 活跃度、动作速度（20%–100%，默认 75%）、眨眼频率（0–30 次/分钟，默认 8）、呼喊间隔、趴睡倾向、状态驱动气泡与行为、提醒灵敏度 |
| 状态与成长 | 5 | 每种属性独立的「每 30 分钟下降点数」下拉框（0–20；默认饱食/体力/清洁 20、心情 5、好感 3） |
| 数据与存储 | 5 | 数据存储位置、自动保存与间隔、自动备份与份数 |
| AI 自言自语 | 11 | 总开关（默认关）、模型服务与接口地址、模型名、API Key（加密保存）、连接测试、现在讲一段、自主频率、说话声音、朗读语速、句子节奏 |

另有动作按钮：浏览/打开数据目录、导出配置、导入配置（校验 + 确认后应用）、迁移并重启、恢复默认设置（可勾选「保留宠物名字」，位于底栏）。

**生效时机**（UI 徽标标注）：

- 即时生效：主题、体型、透明度、字号、阴影、粒子、减少动效、静音音量、气泡、点击穿透、滚轮缩放、快捷键（重新注册）、行为参数（含动作速度与眨眼频率）、宠物名字与称呼；
- 重启生效：数据存储位置、静默启动（琥珀色徽标 + 底栏「迁移并重启」入口）；
- 下次登录生效：开机自启动（写入系统登录项，勾选状态即时可见）。

**保存方式**：主进程内存中的 config 为唯一真源，两个渲染窗口持只读副本，经 `config-changed` 广播双向同步。写盘策略：开关/下拉/文本框即时写、滑杆拖动 300ms 防抖、属性值按 `saveInterval` 节流、窗口关闭与退出强制 flush；统一**原子写**（tmp → rename），写入前自动备份并滚动保留 N 份（`backup/config-<时间戳>.json`）。

**数据目录**：由固定位置的 `bootstrap.json`（始终在系统 userData 目录）引导，避免"配置文件在哪里由配置文件决定"的循环依赖；迁移时先复制后切换、失败自动回滚且不删除源数据。

**边界条件**：

- 配置 JSON 损坏 → 另存为 `config.corrupt-<时间戳>.json`，用默认值启动；
- 类型错误 / 数值越界 / 枚举非法 → 按 schema 逐字段转换、夹紧、回退默认值；
- 旧版扁平配置 → 首次启动自动迁移为 v2 分组结构（迁移前自动备份）；
- 快捷键被占用 → 注册失败自动保留原设置并输出警告；
- 宠物名字为空/含控制字符/超长 → 输入框实时过滤与截断，非法值不写入。

## 三、动画状态机

```
                       ┌──────────────────────────────────────┐
                       │                idle                  │
                       │        （呼吸 / 眨眼 / 决策）          │
                       └───┬───────┬───────┬────────┬──────────┘
             （移动决策）  │       │       │        │  （主动呼喊/饥饿/无聊）
                           ▼       │       ▼        ▼
                        ┌──────┐   │  ┌────────┐  ┌──────┐
                        │ walk │◄──┘  │  run   │  │ meow │
                        └──┬───┘      └───┬────┘  └──┬───┘
              （到边缘/随机）│             │          │ （呼喊后走向光标）
                           ▼             ▼          ▼
                        ┌──────┐   （落地）      ┌──────┐
                        │ jump │──────────────►  │ walk │
                        └──┬───┘                 └──────┘
                           │ 落地
                           ▼
                        ┌─────────┐   睡醒    ┌──────────┐
                        │  sleep  │─────────► │ stretch  │
                        └─────────┘           └──────────┘

   任意状态 ──(用户拖拽)──► drag ──(松手)──► fall ──(落地)──► idle
   任意状态 ──(喂食)──────► walk(走向食物) ──► eat ──► idle
   任意状态 ──(抚摸)──────► pet  ──► idle
   任意状态 ──(逗玩)──────► play ──► idle
```

**过渡平滑策略**：

- 姿态切换采用 **180ms 交叉淡入淡出**（旧姿态淡出、新姿态淡入，同锚点叠加）
- 位移使用 **帧率无关的指数趋近**，避免瞬移
- 起跳/落地加入 **squash & stretch**（落地压缩、起跳拉伸）
- 每个姿态叠加程序化微动（呼吸缩放、走动起伏、奔跑前倾），消除呆板感

## 四、开机自动启动

采用 **Electron `app.setLoginItemSettings`**（首选，无 UAC 弹窗）：

```js
app.setLoginItemSettings({
  openAtLogin: true,
  openAsHidden: true,      // 启动时静默驻留托盘
  path: process.execPath,
  args: ['--autostart'],
});
```

在设置窗口「启动与运行」中打开「开机自启动」即可，状态持久化到配置文件并写入系统登录项。

## 六、素材生成管线（可复现）

素材由 AI 生成后经脚本处理，脚本位于 `../tools/`：

| 脚本 | 作用 |
|------|------|
| `extract_sprite.py` | 自动采样四角推定背景色 → 颜色距离掩码 → 仅保留边界连通背景 → 剔除平台水印 → 腐蚀 + 高斯模糊柔边 |
| `normalize_sprite.py` | 裁剪内容边界 → 等比缩放至目标高度 → 粘贴到 512×512 统一画布并对齐地面基线 |
| `normalize_sequence.py` | **整序列**统一缩放（避免逐帧各自缩放导致大小跳动）+ 以首帧躯干核心为模板做 IoU 匹配水平对齐 |
| `sprite_bounds.py` | 实测各姿态内容顶部边界，生成 `engine/animator.js` 的 `CONTENT_TOP_FALLBACK` 表（气泡定位用） |
| `rebuild_sprites.py` | 素材管线一键重跑：raw 洋红底图 → 抠图 → 归一化，覆盖全部单姿态与 walk/run 序列帧 |
| `test_logic.js` | 无头逻辑冒烟测试：Node `vm` 沙箱 + Canvas mock，驱动数千帧验证状态机、交互、体型边界、阴影/气泡缩放联动与菜单关闭 |

处理命令示例：

```bash
python tools/extract_sprite.py  raw.png  cutout.png
python tools/normalize_sprite.py cutout.png  ../assets-src/sprites-poses/idle.png

# 序列帧：脚本按文件名排序，故须先把原始帧重命名成 walk_1..4 / run_1..4
# （AI 原始文件名形如 Walkframe{one,four,three,two}，字典序为 four→one→three→two，顺序会错乱）
python tools/normalize_sequence.py ../assets-src/raw/frames/walk_1.png ../assets-src/raw/frames/walk_2.png \
       ../assets-src/raw/frames/walk_3.png ../assets-src/raw/frames/walk_4.png \
       --outdir ../app/assets/sprites/frames --prefix walk_ --height 340
```

**姿态清单**（14 个，全部 512×512、内容底边对齐 y=470；其中 13 个已升级为帧序列）：

`idle` `walk` `run` `jump` `stretch` `drag` `sleep` `eat` `play` `pet` `meow` `tailwag` `unhappy`

**序列帧**：`walk_1..4`、`run_1..4`、`idle_1..4`、`eat_1..4`、`play_1..4`、`pet_1..3`、`jump_1..3`、`stretch_1..3`、`sleep_1..3`、`meow_1..3`、`tailwag_1..4`、`unhappy_1..2`、`bath_1..6`（共 47 张，同规格）。

**单次播放**：`jump` / `stretch` 通过 `animator.play(name, fade, { once: true })` 播放到末帧定格；
`fall`（下落）以 `{ startAt: 1 }` 直接从腾空帧开始，落地挤压由 squash 模块承担。

## 七、已知限制与后续可扩展

- 13 个姿态均为 4–6 帧序列 + 帧间 35% 交叉淡化，动作已较流畅；`drag` 仍是单帧静态图（被拎着不晃）。若想更细腻可继续补帧（管线已就绪：`tools/normalize_sequence.py` 支持整序列统一缩放与躯干核心对齐），注意包体与启动耗时随之上升。
- 语音为本地内置素材（`assets/audio/meow/`，.ogg 优先、.wav 兜底），共 15 条精选叫声 + 2 条呼噜音轨；新增叫声同名放入 `assets/audio/meow/` 即可替换，无需改代码。
- 说话气泡文案目前为内置中文短句，可扩展为随机句库。
- 多显示器跨 DPI 拖动时透明窗口尺寸可能轻微漂移（已用 `enforceSize()` 守卫兜底，单屏无此问题）。
