# 设置窗口 · UI 设计规格（评审稿 v1）

> 配套可交互原型：`settings-ui-prototype.html`（本文件描述原型无法完整传达的规格与状态设计）
> 关联方案：`../settings-plan.md`（设置项清单与持久化机制）

---

## 一、设计原则

1. **辅助窗口气质**：设置窗口是从属于宠物的次级窗口 —— 素净、小尺寸、标准标题栏，不与宠物争夺视觉焦点。
2. **改动即所见**：凡是能即时生效的项，改动立刻反映到宠物窗口；只有需要重启的项才出现徽标与等待态。
3. **schema 单一来源**：界面不硬编码任何设置项 —— 分组、控件类型、取值范围、默认值、生效徽标全部由字段定义表驱动。原型本身就是这一机制的验证（原型 JS 中的 `GROUPS` 与正式 `config-schema.js` 同构）。
4. **双主题同构**：浅色 / 深色共用同一套布局与组件，仅替换色彩 token；`auto` 跟随系统。
5. **双语同构**：中英文共用同一布局，文案由 i18n 表提供；不做两套界面。

## 二、窗口与布局栅格

| 项 | 正式实现 | 原型（评审用） |
|----|----------|----------------|
| 窗口尺寸 | **620 × 580**，固定不可缩放 | 720 × 604（放大 1.16 倍便于阅读，比例一致） |
| 标题栏 | 高 36px，系统标题栏 | 高 38px，自绘示意 |
| 左侧导航 | 宽 136px | 宽 150px |
| 内容区 | 内边距 16px 18px | 内边距 18px 22px |
| 底部操作条 | 高 52px | 高 56px |

**行栅格**（内容区每一项）：`标签列 104px + 控件列自适应`，列间距 10px；行内边距 9px 0，行间以 1px 分隔线相隔；辅助说明文字（12px）位于控件正下方，与控件左对齐。

**分组头**：组名（15px/500）+ 一句话说明（12.5px，次级色），下方 14px 留白后进入条目。

**导航**：7 个分组纵向排列，当前组以「淡主色底 + 主色文字 + 500 字重」标识；长英文标签（如 Startup & running）允许折行。

## 四、字体与字号

| 用途 | 字号 / 字重 |
|------|-------------|
| 分组标题 | 15px / 500 |
| 行标签、正文、按钮 | 13px / 400 |
| 辅助说明、单位值、导航英文折行 | 12px / 400 |
| 徽标 | 11.5px / 400 |
| 窗口标题 | 13px / 500 |

字体栈沿用宠物窗口：`"PingFang SC", "Microsoft YaHei", system-ui, sans-serif`；数值列使用 `font-variant-numeric: tabular-nums` 保证滑杆拖动时数字不跳动。

## 五、控件规格

| 控件 | 规格 |
|------|------|
| 文本框 | 高 28px，圆角 7px，内边距 5px 9px；宽度按最大字符数估算（名字类 12 字 ≈ 204px），聚焦显示主色描边 + 3px 半透明焦点环 |
| 下拉框 | 同文本框，最大宽 210px |
| 滑杆 | 原生 range + 主色 `accent-color`；右端固定宽度单位值（66px，右对齐），拖动时实时刷新 |
| 开关（复选） | 15×15px，主色；右侧跟一句 12px 说明文字，整行可点 |
| 次级按钮 | 白底 + 1px 描边，圆角 7px，内边距 5px 12px；hover 加深底色 |
| 主按钮（应用） | 主色底白字；**无改动时禁用**（α 0.5） |
| 徽标 | 高 20px 胶囊，11.5px；两种语义色见 token 表 |
| 只读展示 | 灰底 + 次级文字色（数据目录路径、单实例开关） |

## 六、状态设计

| 状态 | 表现 |
|------|------|
| hover | 行内控件底色微深；按钮底色 `#f4f6f9` |
| focus | 主色描边 + 3px 半透明焦点环（键盘与鼠标一致） |
| 禁用 | 整体 α 0.5 + `cursor: default`；用于联动静音后的音量、关闭通知后的间隔、关闭自动保存后的间隔与份数 |
| 只读 | 灰底次级色（数据目录、单实例），不出现禁用灰 |
| **校验错误** | 输入框红色描边 + 3px 红色焦点环 + 控件下方 12px 红字说明；**同时拦截写入**（值不进入配置） |
| **脏值（未保存）** | 底栏出现「已修改 N 项」；「应用 / 取消」由禁用转为可用 |
| **待重启** | 任一 `重启后生效` 项被改动时，底栏出现琥珀色提示条「有 N 项需重启后生效 · 立即重启」 |
| 保存成功 | 底栏左侧短暂显示绿色反馈（2.6s 自动消失），不打断操作 |

## 七、交互规则

1. **改动即预览**：主题、语言、体型、透明度等即时项在控件上改动的同时生效（原型中切换「主题」下拉或顶部主题开关即可看到窗口换色）。
2. **防抖**：滑杆拖动 300ms 防抖落盘、松手立即写；离散项（开关/下拉/文本框失焦）立即写。
3. **取消 = 回滚快照**：打开窗口时的值构成快照，「取消」恢复快照并重绘表单。
4. **应用 = 落盘**：写 config.json 并清除脏值与重启提示。
5. **恢复默认设置**：全局动作，固定在底栏左端（危险色文字按钮）；正式版点击后弹出确认对话框，并提供「保留宠物名字」勾选。
6. **联动禁用**：静音 → 音量禁用；关气泡 → 气泡时长禁用；关通知 → 通知间隔禁用；关自动保存 → 保存间隔禁用；关自动备份 → 备份份数禁用。联动关系由 schema 的 `blockedBy` / `requires` 字段描述，不写在界面代码里。
7. **命名联动**：修改宠物名字实时更新窗口标题与所有含 `{name}` 占位符的说明文案。
8. **关闭方式**：标题栏 ×、`Esc`、点击窗口外（失焦）均可关闭；关闭即视为「应用」（未落盘的脏值先落盘），与通用桌面应用一致。

## 八、可访问性与键盘

- Tab 顺序：导航 → 自上而下逐行控件 → 底栏按钮；
- 开关：空格切换；滑杆：←/→ 按步长调整、Home/End 到边界；下拉：↑/↓ 选择；
- 焦点环对比明显（3px 半透明主色），深浅主题均 ≥ 3:1；
- 正文与背景对比度 ≥ 4.5:1，辅助文字 ≥ 3:1（深色主题下 `#9a9a9f` on `#252527` ≈ 4.6:1）；
- 「减少动态效果」开启后，本窗口内的过渡动画一并关闭。

## 九、schema 字段 → 控件映射

| 字段类型 | 控件 | 附加能力 |
|----------|------|----------|
| `text` | 文本框 | `max` 截断、控制字符过滤、`allowEmpty` |
| `switch` | 复选框 + 说明 | `ro` 只读、`blockedBy` / `requires` 联动 |
| `range` | 滑杆 + 单位值 | `min/max/step`、`fmt`（%/秒/毫秒/分钟/分秒） |
| `select` | 下拉框 | `opts`（带双语标签） |
| `path` | 只读路径 + 按钮 | `badge`、行内动作 |
| `actions` | 按钮组 | 无配置字段，点即执行 |
| `divider` / `subhead` | 分隔线 / 小标题 | 纯布局 |

每个字段还可携带：`badge`（restart/login）、`hzh/hen`（说明）、`nzh/nen`（开关旁注释）、`{name}`/`{owner}` 占位符。

## 十、评审确认点

1. **信息密度**：当前一屏约 5–7 项、说明文字随行展开 —— 是否偏好更紧凑（说明收纳进 tooltip/问号图标）？
2. **徽标位置**：生效徽标现挂在**行标签下方**（数据存储位置一组可见）—— 是否改挂到控件行右侧？
3. **底栏语义**：「取消 = 回滚快照、关闭 = 视为应用」是否符合你的预期？（另一种常见做法是关闭即丢弃未应用改动）
4. **主色**：当前为蓝 `#4a7fd4`，未强绑定宠物形象 —— 是否希望换成与银渐层呼应的暖灰/银蓝色系？
5. **原型尺寸**：正式窗口按 620×580 实现，若你觉得拥挤可放宽到 680×600。
