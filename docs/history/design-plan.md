# 小猫桌面宠物（Q 版银渐层）设计方案

## 1. 项目目标与范围

开发一款 Windows 桌面宠物程序，主角为基于参考图转化的 Q 版长毛银渐层小猫，达到类似 QQ 宠物的陪伴效果：

- 开机自动启动
- 用户可与之交互：抚摸、逗玩、喂食、呼喊
- 无交互时自主活动：走、跑、跳、趴着睡觉、主动呼喊主人
- 所有动作连贯自然、过渡平滑
- 素材基于已选定的 Q 版萌系风格生成

**本次方案阶段不输出可执行程序**，待方案确认后进入开发实现。

---

## 2. 技术选型

| 维度 | 推荐方案 | 备选方案 | 说明 |
|------|---------|---------|------|
| 运行时框架 | **Electron** | Python + PyQt6 | Electron 对透明无边框窗口、置顶、系统托盘、开机自启支持最成熟 |
| 动画渲染 | HTML5 Canvas 2D | WebGL / CSS sprite | Canvas 2D 足以驱动帧动画，调试简单 |
| 脚本语言 | JavaScript / TypeScript | Python | 与 Electron 天然契合 |
| 状态管理 | 自定义有限状态机（FSM） | Redux / Zustand | 状态规模小，自定义 FSM 更轻量 |
| 自启动 | `app.setLoginItemSettings` + 注册表/启动文件夹回退 | 手动创建快捷方式 | Electron 内置 API 最稳定 |
| 打包发布 | `electron-builder` 生成便携 `.exe` | `electron-forge` | 最终可制作为双击安装/绿色版 |

**选择 Electron 的主要原因**：

1. 支持 `transparent: true` 的无边框窗口，宠物可真正“浮”在桌面。
2. 支持 `alwaysOnTop`，确保不被其他窗口遮挡。
3. 支持 `app.setLoginItemSettings` 一键设置开机自启。
4. 前端 Canvas 动画生态成熟，帧序列、Tween、粒子效果实现直接。
5. 最终可打包为独立 `.exe`，用户无需安装 Node。

## 3. 功能模块划分

### 3.1 窗口宿主模块（Window Host）

- 创建透明无边框置顶窗口（尺寸约 400×400 逻辑区，实际内容自适应）。
- 支持鼠标穿透（点击空白处不影响桌面操作，可选开关）。
- 支持拖拽移动宠物位置。
- 限制宠物活动范围不超出屏幕工作区。
- 提供系统托盘图标：显示/隐藏、设置、退出。

### 3.2 动画引擎模块（Animation Engine）

- 管理所有精灵图（Sprite）资源的加载与缓存。
- 帧动画播放器：按配置 FPS 循环播放序列帧。
- 动画混合器：状态切换时做 150–250ms 的透明度过渡或淡入淡出。
- 变换插值：位置、缩放、旋转使用缓动函数（ease-in-out、spring）。
- 粒子系统：爱心、ZZZ、食物碎屑等。
- 朝向管理：根据移动方向水平翻转。

### 3.3 状态机模块（State Machine）

- 核心有限状态机，负责猫的行为决策与动画切换。
- 每个状态有：进入/更新/退出回调、允许的中断输入、默认持续时间。
- 状态切换时触发过渡动画与音效。

### 3.4 交互模块（Interaction）

- 鼠标悬停检测（命中猫身体区域）。
- 左键单击/长按 = 抚摸。
- 左键按住拖动 = 拖拽移动。
- 右键菜单 = 喂食 / 逗玩 / 呼喊 / 设置 / 退出。
- 快捷键：可配置全局热键（如 `Ctrl + Shift + C`）触发呼喊。

### 3.5 自由活动模块（Autonomous Behavior）

- 决策定时器：每隔几秒根据心情/精力/饱食度选择下一动作。
- 屏幕边界检测：走到边缘时转身或跳跃。
- 物理简化模型：重力、落地反弹、地面约束。
- 属性系统：精力、饱食度、快乐值随时间衰减，交互后恢复。

### 3.6 自启动模块（Auto-start）

- 首选 Electron `app.setLoginItemSettings({ openAtLogin: true, openAsHidden: true })`。
- 备选：写入 `%APPDATA%\Microsoft\Windows\Start Menu\Programs\Startup` 快捷方式。
- 设置面板提供开关，程序启动时读取并同步状态。

### 3.7 配置持久化模块（Config）

- 配置文件 `config.json`：
  - 窗口位置
  - 是否开机自启
  - 音量、动画帧率
  - 是否启用鼠标穿透
  - 上次关闭时的属性状态
- 使用 `electron-store` 或原生 `fs` 读写。

### 3.8 资源与音频模块（Assets）

- 图片：PNG 序列帧 + 道具图标（食物、玩具、爱心）。
- 音频：喵叫、呼噜、进食、铃铛（可选，默认开启但可静音）。
- 所有资源本地加载，无需联网。

## 4. 交互逻辑

| 用户动作 | 触发条件 | 猫的反应 | 状态/动画 | 效果 |
|---------|---------|---------|----------|------|
| 抚摸 | 鼠标悬停 + 左键点击/长按 | 眯眼、蹭手、头顶冒爱心 | PET_HAPPY | 快乐值 +，精力微降 |
| 逗玩 | 右键菜单选“逗玩”或快捷键 | 视线追踪光标/玩具，扑击 | PLAY | 快乐值 +，精力 - |
| 喂食 | 右键菜单选“喂食” | 跑向食物，低头进食 | EAT | 饱食度 +，快乐值微增 |
| 呼喊 | 右键菜单选“呼喊”或快捷键 | 转头看向用户、张嘴喵叫 | MEOW | 快乐值 +，随后跑向光标 |
| 拖拽 | 按住猫身体拖动 | 身体被提起、四肢下垂 | DRAGGED | 无属性变化 |
| 放下 | 释放鼠标 | 下落并轻微反弹 | FALL → IDLE | 无属性变化 |
| 右键空白 | 在宠物上右键 | 弹出功能菜单 | 保持当前状态 | 无 |

**主动行为（无交互时）**：

- 精力高时：WALK / RUN / JUMP。
- 精力低或长时间空闲：SLEEP。
- 快乐值低或随机：MEOW（主动呼喊主人）。
- 饱食度低时：MEOW 频率增加，提示喂食。

## 5. 动画状态机

### 5.1 状态定义

| 状态 | 类别 | 含义 | 可被中断 |
|------|------|------|---------|
| IDLE | 自主 | 待机、呼吸、左右张望 | 是 |
| WALK | 自主 | 慢走 | 是 |
| RUN | 自主 | 小跑 | 是 |
| JUMP | 自主 | 原地跳或跨越边缘 | 是（落下后） |
| FALL | 过渡 | 被放下后的下落 | 否 |
| SLEEP | 自主 | 趴卧睡觉，ZZZ 粒子 | 是（点击/拖拽/呼喊唤醒） |
| MEOW | 自主/交互 | 张嘴叫、抬头看 | 是 |
| EAT | 交互 | 跑向食物、低头咀嚼 | 是 |
| PET_HAPPY | 交互 | 眯眼、蹭手、冒爱心 | 是 |
| PLAY | 交互 | 扑玩具、翻滚、挥舞爪子 | 是 |
| DRAGGED | 交互 | 被鼠标提起、四肢下垂 | 释放后转 FALL |

### 5.2 主要状态转换

```text
IDLE ──(移动决策)──> WALK ──(加速)──> RUN
 │                    │   <──(减速)──┘
 │                    │
 │                 (到边缘/障碍)         
 │                    │
 │                    ▼
 │                   JUMP ──(落地)──> WALK/RUN/IDLE
 │
 ├─(空闲+精力低)──> SLEEP ──(唤醒)──> IDLE
 ├─( attention 定时器 )──> MEOW ──(结束)──> IDLE
 └─( food 出现 )──> EAT ──(吃完)──> IDLE

任意状态 ──(用户拖拽)──> DRAGGED ──(释放)──> FALL ──(落地)──> IDLE
任意状态 ──(用户抚摸)──> PET_HAPPY ──(结束)──> IDLE
任意状态 ──(用户逗玩)──> PLAY ──(结束)──> IDLE
任意状态 ──(用户呼喊)──> MEOW ──(结束)──> WALK(走向光标)
```

### 5.3 过渡平滑策略

- **帧动画混合**：切换状态时，旧动画继续播放至 fade-out（约 150ms），新动画 fade-in。
- **位移插值**：所有位置变化使用 `easeOutQuad` 或弹簧模型，避免瞬间瞬移。
- **落地缓冲**：JUMP / FALL 落地时加入 0.1 秒 squash（Y 轴压缩 + X 轴拉伸）。
- **转身过渡**：水平翻转不直接镜像，而是带 50ms 的缩放 x: 1 → 0.2 → -1 的“翻页”效果。
- **表情过渡**：眨眼、瞳孔移动使用独立图层，与身体动画解耦。

## 6. 自启动机制

### 6.1 方案 A：Electron 原生 API（首选）

```js
app.setLoginItemSettings({
  openAtLogin: true,
  openAsHidden: true, // 启动时不显示主窗口，托盘静默运行
  path: app.getPath('exe'),
  args: ['--autostart']
});
```

- 优点：最稳定，UAC 无弹窗。
- 限制：仅在已安装/打包后有效，开发模式可能不生效。

### 6.2 方案 B：启动文件夹快捷方式（回退）

- 目标目录：`%APPDATA%\Microsoft\Windows\Start Menu\Programs\Startup`
- 操作：写入指向主程序 `.exe` 的 `.lnk` 快捷方式。
- 用于 Electron API 失效或用户偏好传统方式时。

### 6.3 设置面板

- 提供“开机自动启动”开关。
- 启动时读取当前状态并同步 UI。
- 切换时即时写入配置并调用对应 API。

## 8. 动画连贯性与过渡细则

1. **帧率**：动画逻辑更新 60 FPS，角色动作序列帧按 8–12 FPS 播放。
2. **混合时间**：
   - 同类动作切换（WALK ↔ RUN）：100ms
   - 动作 ↔ IDLE：150ms
   - 交互动作 ↔ 自主动作：200ms
   - 落地/跳跃：80ms squash
3. **移动速度**：
   - WALK：80 px/s
   - RUN：180 px/s
   - JUMP：水平 150 px/s，垂直初速度 350 px/s，重力 900 px/s²
4. **随机决策间隔**：3–8 秒，避免机械感。
5. **边界处理**：距屏幕边缘 50px 时减速并触发转身或跳跃。
6. **视线追踪**：头部/眼睛图层单独旋转，始终看向光标或食物/玩具。
