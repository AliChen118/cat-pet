# 文档目录

本目录是桌面宠物的**规格与决策文档**，面向维护者：说明系统为什么这样实现、有哪些硬性参数与约束、改动时必须同步什么。

**使用说明不在这里** —— 安装、交互、功能清单见 [`../app/README.md`](../app/README.md)；仓库总览、下载、构建命令见 [`../README.md`](../README.md)。

## 四、文档约定

1. **单一来源优先**：数值、阈值、权重只在代码里维护一份；文档写"结论 + 真源位置"，不复制整张表除非该表本身是评审依据。
2. **不写"待确认"**：方案阶段的疑问一律留在 `history/`；现行分册只描述**已落地**的行为。未实现的想法写在 07 的「已知限制」。
3. **改动即同步**：改帧数/设置项/阈值/情境时，同一提交内更新对应分册与 `app/README.md` 的相关段落（清单见 07 末节）。
4. **历史归档不具约束力**：`history/` 里的方案保留当时语境，与现行分册冲突时**一律以现行分册与代码为准**。
